# Production readiness gate

Baseline hiện tại là nền móng chạy được và đã qua type-check, unit test, production build, API smoke test và kiểm tra UI desktop/mobile. Chỉ go-live sau khi hoàn tất toàn bộ cổng dưới đây.

## Nghiệp vụ

- [ ] Workshop với Kinh doanh, Kho, Kế toán; chốt owner và RACI.
- [ ] Từ điển dữ liệu, trạng thái, đánh số, ngưỡng duyệt, bảng giá, hạn mức và mẫu in được ký duyệt.
- [ ] Bổ sung hủy/đảo, trả hàng, kiểm kê, xuất/nhập một phần theo quy tắc thực tế.
- [ ] Báo cáo Excel/PDF đối soát với biểu mẫu hiện tại.
- [ ] Ba đại diện nghiệp vụ ký UAT.
